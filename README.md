# Student Grade Calculator

## Description
This program calculates your electricity bill and consumption using your previous and current meter reading.

# Version 1 - Original code without input validation
- Input: Accepts a customer's name and your previous and current meter reading.
- Process: Calculates and displays the electricity consumption and electricity bill.
- Output: Customer's name, electricity consumption and electricity bill.
- Does not include input validation.

# Version 2 - Code with input validation
- Input: Accepts a customer's name that is not empty and your previous meter reading that is at least 0 and your current meter reading that is at least your previous meter reading.
- Process: Calculates and displays the electricity consumption and electricity bill.
- Output: Customer's name, electricity consumption and electricity bill.
- Includes input validation.
